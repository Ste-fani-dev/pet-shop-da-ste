# 🐾 Pet Shop da Ste

Sistema de cadastro de clientes e pets desenvolvido em Python.

Este projeto foi criado com o objetivo de praticar lógica de programação, 
estruturas de dados e organização de código.

## 🚀 Funcionalidades atuais

✅ Cadastro de clientes  
✅ Listagem de clientes  
✅ Cadastro de pets  

## 🛠️ Tecnologias utilizadas

- Python 3.12
- Git
- GitHub

## 📚 Conceitos praticados

- Variáveis
- Entrada de dados com input()
- Estruturas condicionais (if/elif/else)
- Laço de repetição while
- Listas
- Dicionários
- Conversão de tipos com int()
- Organização inicial de projeto
